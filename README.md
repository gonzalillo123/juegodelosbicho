# Biosfera espacial

Simulación de ecosistema en tiempo real, hecha solo con HTML, CSS y JavaScript (Canvas 2D). Sin dependencias.

- Naves humanas (herbívoros) que minan meteoritos y huyen de los aliens.
- Aliens (carnívoros) con cono de percepción de 45°.
- Parásitos cósmicos que drenan vida a los aliens.
- Meteoritos que crecen, algunos radiactivos.
- Reproducción con genes y mutaciones, vejez, eventos aleatorios y gráfica de poblaciones.

## Uso
Abre `index.html` en el navegador. Todos los parámetros están en el objeto `CONFIG` al inicio del script.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.
